ⓘ How it works

Paste links from your apps into a class (a Song Writer song, a xylophone layout, an Ostinato Builder lesson…). Students tap their class and see only today's lesson. When a lesson is done, move it to the Filing Cabinet: students can still find it there to practice. Your changes stay in this browser until you Publish; students see them about a minute later.

Connect to GitHub

Publish uses the same key as the Librarian. If you connected the Librarian in this browser, you're already connected here. GitHub shows a key only once, so if you didn't save yours, make a new one:

  1. On GitHub, signed in as Eagleviewmusic, open New fine-grained access key.
  2. Name: Classroom. Expiration: up to a year.
  3. Repository access: Only select repositories → eagleviewmusic.github.io.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Press Generate token, copy it, paste it below. Save it in your password manager for your other computers.

The key stays in this browser only. Connect on your own computer, not a shared classroom one.
