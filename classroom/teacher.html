ⓘ How it works

Paste links from your apps into a class (a Song Writer song, a xylophone layout, an Ostinato Builder lesson…). Students tap their class and see only today's lesson. When a lesson is done, move it to the Filing Cabinet: students can still find it there to practice. Your changes stay in this browser until you Save file to publish and the file goes on the site.
